# 场景工作流

按用户目标选下列路径，不强制跑完无关阶段。开始先保留当前文件、确定作用域和输出位置；新文件也不应覆盖同名用户文件。

## 新建或修改模型

1. 读已有文件/集合/单位与选中对象，取图。整理要求中的尺寸、朝向、对象命名、材质、用途、输出格式；只有影响结果的缺口才问选择题。
2. 简单几何验证整体比例。分面硬表面用基本体/挤出/倒角；光滑硬表面按需要组织 Bevel 与 Subdivision；重复零件优先阵列/实例；轴对称用旋转截面。先主体后细节，不靠面数证明质量。
3. 将新增对象放入独立集合、使用稳定前缀，显式引用需要修改的对象，保留用户对象。关键形体改动后看图，对照尺寸再继续。
4. 清理法线、重复点、退化面和不需要的临时对象；按用途检查修改器、UV、材质、贴图、轴向和原点。打印/游戏/展示的验收要求不同，按用户用途选门。
5. 保存可编辑 `.blend`，按要求导出 GLB/FBX/OBJ 等。核对真实文件、贴图与导出后尺度；交付前遵循 [验收](acceptance.md)。

## 按参考图还原

- 无参考图时只做品类、部件、形体与比例假设，记录待确认项，不把猜测尺寸写成既定规格。
- 拿到图先实际看图，再 `img_digest` 看轮廓/孔/对称/可读性，必要时 `img_probe` 裁剪量局部。
- 已知长度用 `img_measure`，多视用 `img_calib`。没有标定只能说像素和相对比例；三张正交图也可能有不同缩放，应逐视标定后用共享物理尺寸互检。单应校正只对取点平面成立，不能把立体物各深度都当精确毫米。
- 将确认尺寸、来源、相机、单位与未确认假设保存在项目规格里。先包络，再截面/细节；选择 catalog 对应 shape/vehicle 等操作，不猜截面参数。
- 参数化物体可用 `shapesolve_solve` 拟合轮廓，但正交机位/ortho_scale 必须对齐；用独立渲染和尺寸复核拟合结果。
- `visualreport_report` 要同机位、分辨率、裁切；逐视对比。IoU 只能说明轮廓重合度，不证明厚度、内部结构、材质和整体相似。

## 装配体

先确定一份统一清单：零件 id、文件、尺寸、坐标系、接口、连接关系、名义间隙、允许的隐藏交叠。先 `asm_manifest`，再 `asm_scan` 区分 clash / hidden_ok / contact / gap / float / contained / unresolved。

只在已授权范围内做 `asm_repair(policy="safe")` 的平移/吸附；布尔、缩放、焊接等改变几何的操作先文件快照，确认不会破坏接口。设计允许的交叠不能一律消掉；AABB 重叠不能证明三角网格穿模或连接强度。装配/接口门通过后再 `asm_export`，核对 manifest 和 merge ledger。

多人或多 agent 协作只有用户确实要求时才展开。独立 worker、文件与对象前缀隔离；共用同一规格；不要两个写者同时修改同一 `.blend`。合并后重新验接口与全局装配。

## 白模与渲染参考包

`blockout_base/batch` 负责比例白模；`blockout_refsheet` 可交前/侧/顶/iso 四视图、拼图与 JSON；`blockout_turntable` 可给 MP4。确认目标单位、forward/up、相机和可读部件。没有 FFMPEG 时 PNG 序列回退应报告 degraded，不能说 MP4 已完成。白模不能冒充精细成品。

普通渲染优先小尺寸低采样验证相机、构图、光源和材质，再增加质量；先测每帧耗时再承诺动画时间。长渲染走作业层，记录句柄和输出目录；用 watch/抽样看中间关键帧，检查主体遮挡、出画、闪烁和穿模。
